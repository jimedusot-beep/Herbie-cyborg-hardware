# Beginner guide

One robot, three notebooks: [Herbie](https://github.com/jimedusot-beep/Herbie) is the brain; [3D-vision](https://github.com/jimedusot-beep/3D-vision) is the body; [Herbie-cyborg-hardware](https://github.com/jimedusot-beep/Herbie-cyborg-hardware) is the electronics. Shared component IDs help track each real part. Links do not make electronics work automatically. Verify exact components, power and fit before wiring.
